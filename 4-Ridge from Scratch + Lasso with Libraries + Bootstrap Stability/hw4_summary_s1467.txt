This project explored the application of regularized machine learning techniques, specifically Ridge and Lasso regression, to address the structural challenges of a high-dimensional dataset (n=150, p=40) suffering from severe block multicollinearity. Standard Ordinary Least Squares (OLS) regression inherently fails in this environment, as it cannot reliably distribute predictive weights among highly correlated groups, leading to inflated variance and extreme overfitting.

To resolve this, we first implemented Ridge Regression (L2 penalty) entirely from scratch, utilizing both closed-form matrix algebra and iterative gradient descent. Optimized via 5-fold cross-validation, Ridge successfully stabilized the model by shrinking the coefficients of correlated features evenly toward zero to distribute predictive responsibility. However, Ridge lacks the mathematical mechanism to perform feature selection. Consequently, the final model retained all 40 predictors, leaving it highly complex and difficult to interpret for practical stakeholder use.

We then contrasted this approach with Lasso Regression (L1 penalty). Exploiting the absolute-value geometry of the L1 constraint, Lasso acted as an aggressive, automated feature selector. It successfully forced the vast majority of redundant coefficients to exactly zero, isolating a sparse subset of truly active variables. While this yielded a highly interpretable final equation, our subsequent diagnostic testing revealed a critical algorithmic vulnerability.

To assess the robustness of this sparsity, we engineered a 200-iteration Bootstrap resampling simulation. This final analysis exposed Lasso's primary flaw: profound selection instability. Because the dataset contains tightly correlated blocks of features, Lasso arbitrarily swapped which variable it selected to represent a block across different bootstrap samples. Very few predictors demonstrated an acceptable survival rate across realities.

Ultimately, this analysis highlights a fundamental statistical learning tradeoff: Ridge offers a highly stable but mathematically dense solution, while Lasso provides clean, sparse interpretability at the cost of erratic, highly sensitive variable selection.
